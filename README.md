# Bibliothèque

Application Java de gestion de bibliothèque développée avec Maven et JavaFX.

## Fonctionnalités

* Gestion des livres
* Gestion des usagers
* Gestion des emprunts
* Sauvegarde JSON
* Importation MARC
* Interface JavaFX

## Technologies utilisées

* Java
* Maven
* JavaFX
* JSON

## Exécution du projet

```bash
mvn clean install
mvn javafx:run
```

## Structure du projet

* `model/` : classes métiers
* `service/` : logique applicative
* `controller/` : contrôleurs
* `view/` : interface utilisateur
* `data/` : sauvegardes JSON
