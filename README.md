#  Système de Gestion de Bibliothèque - Cégep

Application Java de gestion de bibliothèque scolaire avec interface graphique JavaFX. L'application permet la gestion des livres, des usagers (étudiants, professeurs, visiteurs), des emprunts et des retours.

##  Prérequis

| Logiciel | Version minimale | Téléchargement |
|----------|-----------------|----------------|
| Java JDK | 24 | [Oracle](https://www.oracle.com/java/technologies/downloads/) / [OpenJDK](https://adoptium.net/) |
| IntelliJ IDEA | 2021.3 ou plus | [JetBrains](https://www.jetbrains.com/idea/download/) |
| Maven | 3.6+ (inclus dans IntelliJ) | - |

> **Note importante** : Aucune configuration manuelle n'est nécessaire. Le projet utilise Maven pour gérer automatiquement toutes les dépendances (JavaFX, Gson, JUnit).
